## Hybrid Search

Hybrid Search는 키워드 기반 검색과 의미 기반 검색을 함께 사용하는 검색 방식이다.

검색 시스템에서 문서를 찾을 때 한 가지 방식만 사용하면 한계가 생길 수 있다.

Sparse Vector 검색은 정확한 단어를 잘 찾지만, 표현이 다르면 관련 문서를 놓칠 수 있다.

Dense Vector 검색은 비슷한 의미의 문서를 잘 찾지만, 정확한 용어나 코드가 중요한 검색에서는 부정확할 수 있다.

Hybrid Search는 이 두 방식을 결합해 검색 품질을 높인다.

---

## Sparse Vector 검색

Sparse Vector 검색은 키워드 기반 검색 방식이다.

문서 안에 특정 단어가 포함되어 있는지, 검색어와 얼마나 정확히 일치하는지를 기준으로 문서를 찾는다.

대표적인 방식으로는 TF-IDF, BM25가 있다.

정확한 단어가 중요한 검색에 강하다.

하지만 같은 의미라도 표현이 다르면 검색에 실패할 수 있다.

---

## Dense Vector 검색

Dense Vector 검색은 의미 기반 검색 방식이다.

문장이나 문서를 임베딩 모델을 이용해 벡터로 변환하고, 벡터 간의 거리를 비교해 의미가 비슷한 문서를 찾는다.

Dense Vector 검색은 의미적 유사성을 파악할 수 있다.

따라서 사용자가 문서에 있는 단어와 다른 표현을 사용해도 관련 문서를 찾을 가능성이 높다.

하지만 Dense Vector 검색은 정확한 문자열이 중요한 검색에서는 약할 수 있다.

---

## Hybrid Search의 원리

Hybrid Search는 Sparse Vector 검색과 Dense Vector 검색을 동시에 수행한다.

검색 과정은 다음과 같다.

1. 사용자의 검색어를 입력받는다.
2. Sparse Vector 검색으로 키워드가 일치하는 문서를 찾는다.
3. Dense Vector 검색으로 의미가 비슷한 문서를 찾는다.
4. 두 검색 결과를 합친다.
5. 각 점수를 조합해 최종 순위를 정한다.

간단히 표현하면 다음과 같다.

```
Hybrid Score = α × Dense Score + (1 - α) × Sparse Score
```

여기서 `α`는 의미 기반 검색을 얼마나 중요하게 볼지 정하는 값이다.

## 검색 실패 보완

키워드 기반 검색만 사용하면 표현이 다른 문서를 놓칠 수 있다.

Hybrid Search는 Dense Vector 검색을 함께 사용하기 때문에 단어가 달라도 의미가 비슷한 문서를 찾을 수 있다.

반대로 의미 기반 검색만 사용하면 정확한 용어가 중요한 검색에서 실패할 수 있다.

Dense Vector 검색만 사용하면 단순히 의미만 비슷한 문서를 가져올 수 있다.

Hybrid Search는 Sparse Vector 검색을 함께 사용하여 정확한 키워드가 포함된 문서를 높은 순위에 올릴 수 있다.

---

## 결론

Hybrid Search는 Sparse Vector 검색과 Dense Vector 검색의 장점을 결합한 검색 방식이다.

키워드 검색만 사용하면 표현이 다른 문서를 놓칠 수 있고, 의미 검색만 사용하면 정확한 용어나 코드가 중요한 문서를 놓칠 수 있다.

Hybrid Search는 두 검색 방식을 함께 사용하여 이러한 한계를 보완한다.
