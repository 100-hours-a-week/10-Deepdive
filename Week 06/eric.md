# Sparse Vector와 Dense Vector 비교

## 1. Sparse Vector 란?

Sparse Vector는 문서에 등장한 단어를 기준으로 수치화 합니다.

예를 들어 전체 단어 목록이 다음과 같다고 하면,

```text
[카카오, 로그인, 오류, 카카오테크 부트캠프, 인증]
```

문서가 다음과 같을 때,

```text
카카오 로그인 오류 해결
```

벡터는 다음처럼 표현됩니다.

```text
[1, 1, 1, 0, 0]
```

즉, 문서에 실제로 등장한 단어를 중심으로 벡터를 만들고, 검색합니다.

대표적인 방식으로는 Bag of Words, TF-IDF, BM25 등이 있습니다.

---

## 2. Sparse Vector의 특징

Sparse Vector는 대부분의 값이 0인 입니다.

### 장점

* 특정 키워드가 포함된 문서를 찾는 데 강하다.
* 검색 결과가 왜 나왔는지 설명하기 쉽다.
* 정확한 단어 매칭이 필요한 검색에 적합하다.

### 단점

* 같은 의미라도 표현이 다르면 잘 찾지 못할 수 있다.
* 문맥이나 의미를 깊게 이해하지 못한다.
* 동의어, 유사어, 문장 전체의 의도 파악에는 약하다.

---

## 3. Dense Vector 란?

Dense Vector는 문서의 의미를 여러 차원의 실수으로 표현하는 방식입니다.
단어가 정확히 일치하는지보다, 문장이나 문서가 담고 있는 의미가 얼마나 비슷한지를 기준으로 검색합니다.

Dense Vector는 보통 Word2Vec, BERT, Sentence-BERT, OpenAI Embedding 같은 임베딩 모델을 사용하여 생성된다.

예를 들어

```text
서버가 갑자기 느려졌다.
API 응답 시간이 증가했다.
```

임베딩 모델은 이 문장을 다음과 같이 변환합니다.

| 문장              |   차원 1 |    차원 2 |   차원 3 | ... |  차원 999 | 차원 1000 |
| --------------- | -----: | ------: | -----: | --: | ------: | ------: |
| 서버가 갑자기 느려졌다    | 0.0312 | -0.1547 | 0.0821 | ... | -0.0453 |  0.1109 |
| API 응답 시간이 증가했다 | 0.0348 | -0.1492 | 0.0795 | ... | -0.0418 |  0.1073 |

각 숫자는 특정 단어의 등장 여부를 의미하는 것이 아니라, 문장의 의미적 특징을 나타낸다.

두 문장의 표현이 달라도 의미가 비슷하면 벡터 값도 비슷한 형태를 가집니다.

즉, Dense Vector는 단어가 직접 일치하는지보다 문장 전체의 의미가 얼마나 가까운지를 기준으로 검색하는 것 입니다.

---

## 4. Dense Vector의 특징

Dense Vector는 대부분의 값이 0이 아닌 실수값으로 채워진 벡터이다.
각 숫자는 사람이 직접 해석하기 어렵지만, 문서의 의미적 특징을 압축해서 담고 있다.

### 장점

* 표현이 달라도 의미가 비슷하면 검색할 수 있다.
* 문맥과 의도를 반영할 수 있다.
* 자연어 질의, 추천 시스템, RAG 검색에 적합하다.
* 동의어, 유사 표현, 문장 단위 검색에 강하다.

### 단점

* 검색 결과가 왜 나왔는지 설명하기 어렵다.
* 정확한 키워드가 반드시 포함되어야 하는 검색에서는 약할 수 있다.
* 임베딩 모델의 품질에 따라 검색 성능이 크게 달라진다.
* 특정 고유명사, 코드, 숫자, 약어 검색에서는 Sparse Vector보다 불리할 수 있다.

---

## 5. 핵심 차이

| 구분     | Sparse Vector   | Dense Vector        |
| ------ | --------------- | ------------------- |
| 검색 기준  | 단어가 직접 일치하는지    | 의미가 비슷한지            |
| 대표 방식  | TF-IDF, BM25    | Embedding, BERT     |
| 강점     | 정확한 키워드 검색      | 의미 기반 검색            |
| 약점     | 표현이 다르면 놓칠 수 있음 | 정확한 키워드 검색이 약할 수 있음 |
| 적합한 검색 | 고유명사, 코드, 기술 용어 | 자연어 질문, 유사 의미 검색    |


## 6. 키워드가 명확한 질의 예시

### 질의

```text
주문번호 28번 주문 상태
```

### 문서 A

```text
주문번호 28번 주문이 완료되었습니다.
```

### 문서 B

```text
주문 요청시 10분정도 소요됩니다.
```

### 검색 결과 차이

Sparse Vector는 `주문번호`, `28`, 주문이라는 단어가 직접 포함된 문서 A를 더 잘 찾게됩니다.
특히 `주문번호`, `28`처럼 정확히 일치해야 하는 값은 단어 매칭이 매우 중요합니다.

Dense Vector는 문서 B도 주문 상태와 의미적으로 관련 있다고 판단할 수 있다.
하지만 사용자가 원하는 것은 일반적인 주문 소요 시간 안내가 아니라, 특정 주문번호에 대한 정보입니다.

따라서 키워드가 명확한 질의에서는 Sparse Vector가 더 유리합니다.

---

## 7. 표현은 다르지만 의미가 비슷한 질의 예시

### 질의

```text
서버가 갑자기 느려지는 이유
```

### 문서 A

```text
서버가 느려지는 원인과 해결 방법
```

### 문서 B

```text
트래픽 증가로 인해 API 응답 시간이 지연되는 문제 분석
```

### 검색 결과 차이

Sparse Vector는 `서버`, `느려지는` 같은 단어가 포함된 문서 A를 찾습니다.
하지만 문서 B는 단어가 많이 겹치지 않기 때문에 관련성이 낮게 나올 수 있다.

Dense Vector는 문서 B도 성능 저하 문제와 관련 있다고 판단하여 같이 검색 합니다.
즉, 표현이 달라도 의미가 비슷하면 검색 하게됩니다.

따라서 의미 기반 검색에서는 Dense Vector가 유리합니다.

---

## 8. 결론

Sparse Vector는 단어가 직접 일치하는지를 기준으로 검색하기 때문에 기술 용어, 고유명사, 코드명처럼 키워드가 중요한 검색에 강합니다.

Dense Vector는 문장의 의미가 비슷한지를 기준으로 검색합니다.
그래서 사용자의 표현과 문서의 표현이 달라도 의미가 비슷하면 검색이 가능합니다.

실제 검색 시스템에서는 두 방식을 함께 사용하는 하이브리드 검색도 많이 사용됩니다.
Sparse Vector는 정확한 키워드 매칭을 보완하고, Dense Vector는 의미 기반 검색을 보완하며 사용됩니다.
