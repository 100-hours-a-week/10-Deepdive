# RNN과 LSTM이 텍스트 시퀀스 데이터를 처리하는 차이

## 1. 텍스트 시퀀스 데이터란?

텍스트 데이터는 단어들이 **순서대로 이어진 데이터**이다.

예를 들어,

> 나는 밥을 먹었다.

와

> 밥은 나를 먹었다.

는 같은 단어를 포함하지만, 단어의 순서가 달라지면서 의미가 완전히 달라진다.

따라서 자연어 처리 모델은 단어 하나만 보는 것이 아니라,
**앞에 나온 단어들이 뒤에 나오는 단어의 의미에 어떤 영향을 주는지** 이해해야 한다.

이처럼 순서가 중요한 데이터를 처리하기 위해 등장한 대표적인 모델이 **RNN**이고,
RNN의 한계를 보완하기 위해 발전한 구조가 **LSTM**이다.

---

## 2. RNN의 기본 개념

RNN은 **Recurrent Neural Network**, 즉 순환 신경망이다.

RNN의 핵심 아이디어는 다음과 같다.

> 현재 입력을 처리할 때, 이전 시점의 정보를 함께 사용한다.

예를 들어,

```text
나는 → 오늘 → 학교에 → 간다
```

라는 문장이 있다면 RNN은 단어를 앞에서부터 하나씩 읽는다.

각 단계에서 RNN은 두 가지 정보를 사용한다.

1. 현재 입력 단어
2. 이전 시점의 hidden state

즉, RNN은 다음과 같은 방식으로 작동한다.

```text
현재 입력 + 이전 기억 → 현재 기억
```

이 구조 덕분에 RNN은 단어의 순서를 반영할 수 있고,
짧은 문장이나 간단한 시퀀스 데이터에서는 잘 작동한다.

---

## 3. RNN의 한계: 장기 의존성 문제

하지만 RNN에는 중요한 한계가 있다.
바로 **긴 문장에서 앞부분의 정보를 잘 기억하지 못한다는 점**이다.

예를 들어 다음 문장을 보자.

> 내가 어릴 때부터 좋아했고, 힘들 때마다 위로가 되었던 노래는 비틀즈의 Yesterday이다.

이 문장에서 마지막의 **“Yesterday이다”**를 이해하려면
앞부분의 **“노래는”**이라는 정보를 기억해야 한다.

하지만 RNN은 모든 정보를 하나의 hidden state에 계속 압축해서 전달한다.
문장이 길어질수록 앞부분 정보는 여러 단계를 거치면서 점점 약해질 수 있다.

이 문제를 **장기 의존성 문제(Long-Term Dependency Problem)**라고 한다.

또한 학습 과정에서는 **기울기 소실(Vanishing Gradient)** 문제가 발생할 수 있다.
즉, 뒤쪽 단어에서 발생한 학습 신호가 앞쪽 단어까지 충분히 전달되지 못하는 것이다.

쉽게 말하면,

> RNN은 문장을 순서대로 읽을 수는 있지만, 문장이 길어질수록 앞에서 읽은 중요한 내용을 잊기 쉽다.

---

## 4. LSTM의 등장

LSTM은 **Long Short-Term Memory**의 약자이다.
이름 그대로 긴 기억과 짧은 기억을 함께 다루기 위해 만들어진 구조이다.

LSTM은 RNN의 장기 의존성 문제를 완화하기 위해
**Cell State**와 **Gate 구조**를 도입했다.

RNN이 hidden state 하나로 정보를 전달한다면,
LSTM은 다음 두 가지 상태를 사용한다.

```text
Hidden State + Cell State
```

여기서 **Cell State**는 장기 기억을 담당하는 통로이다.
중요한 정보는 오래 유지하고, 불필요한 정보는 제거할 수 있다.

---

## 5. LSTM의 핵심: Gate 구조

LSTM에는 대표적으로 세 가지 gate가 있다.

| Gate        | 역할                     |
| ----------- | ---------------------- |
| Forget Gate | 이전 기억 중 버릴 정보를 결정      |
| Input Gate  | 새로 들어온 정보 중 저장할 정보를 결정 |
| Output Gate | 현재 시점에서 출력할 정보를 결정     |

즉, LSTM은 정보를 무조건 계속 넘기는 것이 아니라,

```text
무엇을 잊을지
무엇을 저장할지
무엇을 출력할지
```

를 선택한다.

이 점이 RNN과 LSTM의 가장 큰 차이이다.

RNN은 이전 정보를 계속 hidden state에 압축해서 전달하지만,
LSTM은 gate를 통해 중요한 정보와 덜 중요한 정보를 구분한다.

따라서 LSTM은 긴 문장에서도 핵심 정보를 더 오래 유지할 수 있다.

---

## 6. RNN과 LSTM 비교

| 구분      | RNN                | LSTM                         |
| ------- | ------------------ | ---------------------------- |
| 기억 구조   | Hidden state 하나 사용 | Hidden state + Cell state 사용 |
| 정보 처리   | 이전 정보를 계속 압축       | 정보를 선택적으로 저장, 삭제, 출력         |
| 긴 문장 처리 | 앞부분 정보를 잊기 쉬움      | 중요한 정보를 오래 유지 가능             |
| 주요 문제   | 장기 의존성, 기울기 소실     | 구조가 복잡하고 계산량이 많음             |
| 핵심 특징   | 단순한 순차 처리          | 기억을 관리하는 순차 처리               |

---

## 7. 결론

RNN과 LSTM은 모두 텍스트처럼 순서가 중요한 데이터를 처리하기 위한 모델이다.

RNN은 현재 입력과 이전 hidden state를 사용하여 문맥 정보를 전달한다.
하지만 모든 정보를 하나의 hidden state에 압축하기 때문에,
문장이 길어질수록 앞부분의 중요한 정보가 사라지는 문제가 발생한다.

반면 LSTM은 **Cell State와 Gate 구조**를 통해
중요한 정보는 오래 유지하고, 불필요한 정보는 제거한다.

따라서 RNN과 LSTM의 차이는 단순히 구조의 차이가 아니라,
**텍스트 속 정보를 어떻게 기억하고 관리하느냐의 차이**라고 볼 수 있다.

한 문장으로 정리하면 다음과 같다.

> RNN은 문장을 순서대로 읽는 모델이고, LSTM은 그중 중요한 정보를 선택적으로 기억하는 모델이다.
