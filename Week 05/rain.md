# 배치 정규화 vs 레이어 정규화 비교 분석

> 두 정규화 방법의 원리, 차이, 사용처 비교 분석

---

## 1. 배치 정규화 (Batch Normalization)

### 핵심 아이디어

**"같은 피처, 여러 샘플"** — 열(↕) 방향으로 묶어서 평균·분산 계산

| 샘플 | 피처1 | 피처2 | 피처3 |
|------|-------|-------|-------|
| 샘플1 | **0.5** | 3.1 | 7.2 |
| 샘플2 | **1.2** | 2.8 | 8.1 |
| 샘플3 | **0.8** | 3.5 | 7.5 |
| 샘플4 | **0.3** | 2.9 | 6.9 |

→ 피처1 열(0.5, 1.2, 0.8, 0.3)을 모아서 평균·분산 계산 후 정규화

### 수식

    μ = (1/m) Σ xᵢ          ← 배치 평균
    σ² = (1/m) Σ (xᵢ - μ)²  ← 배치 분산
    x̂ = (x - μ) / √(σ² + ε)
    y = γ × x̂ + β           ← γ,β: 학습되는 파라미터

### 강점과 약점

| 구분 | 내용 |
|------|------|
| 강점 | 이미지/CNN에서 매우 효과적 |
| 약점 | 배치가 작으면 평균 부정확 → 성능 급락 |
| 추론 시 | 학습 중 저장한 이동 평균 사용 (학습과 동작 다름) |

### 왜 CNN·이미지에 쓰이나

- 이미지는 크기가 항상 고정 → 피처 수가 항상 같아서 열 방향 묶기 가능
- 배치를 32~128개씩 크게 쓸 수 있음 → 평균이 안정적
- 대표 모델: **ResNet, VGG**

## 2. 레이어 정규화 (Layer Normalization)

### 핵심 아이디어

**"한 샘플, 모든 피처"** — 행(↔) 방향으로 묶어서 평균·분산 계산

| 샘플 | 피처1 | 피처2 | 피처3 |
|------|-------|-------|-------|
| **샘플1** | **0.5** | **3.1** | **7.2** |
| 샘플2 | 1.2 | 2.8 | 8.1 |

→ 샘플1의 값(0.5, 3.1, 7.2)을 모아서 평균·분산 계산 후 정규화

### 수식

    μ = (1/H) Σ xⱼ          ← 피처 평균
    σ² = (1/H) Σ (xⱼ - μ)²  ← 피처 분산
    x̂ = (x - μ) / √(σ² + ε)
    y = γ × x̂ + β           ← γ,β: 학습되는 파라미터

> 수식 구조가 배치 정규화와 동일. 차이는 m(배치 수)으로 나누냐, H(피처 수)로 나누냐.

### 강점과 약점

| 구분 | 내용 |
|------|------|
| 강점 | 배치 크기 무관, 문장 길이 달라도 동작 |
| 약점 | 이미지엔 배치 정규화보다 상대적으로 비효율 |
| 추론 시 | 학습과 완전히 동일하게 계산 (단순, 버그 없음) |

### 왜 Transformer·NLP에 쓰이나

**이유 1 — 문장 길이가 다 달라서**

| 문장 | 피처1 | 피처2 | 피처3 | 피처4 |
|------|-------|-------|-------|-------|
| "밥 먹었어?" | 0.5 | 1.2 | 0.3 | - |
| "오늘 점심에 밥 먹었어?" | 0.5 | 1.2 | 0.3 | 0.8 |

→ 배치 정규화는 피처4 열을 못 모음 (짧은 문장엔 피처4가 없음)
→ 레이어 정규화는 각 문장 안에서만 계산 → 길이 상관없음

**이유 2 — 배치를 크게 못 써서**

- GPT, BERT는 파라미터가 수백억 개 → GPU 메모리 부족
- 배치를 1~8개 수준으로 작게 쓸 수밖에 없음
- 배치 정규화는 배치 2~4개면 평균이 엉터리 → 레이어 정규화 사용
- 대표 모델: **GPT, BERT**

## 3. 비교 분석

| 비교 항목 | 배치 정규화 | 레이어 정규화 |
|-----------|------------|--------------|
| 정규화 방향 | 열↕ (피처 기준) | 행↔ (샘플 기준) |
| 배치 크기 의존 | 클수록 안정적 | 완전 무관 |
| 추론 시 동작 | 저장된 이동 평균 사용 | 학습과 동일하게 계산 |
| 데이터 크기 | 고정 크기에 적합 | 가변 크기도 OK |
| 주 사용처 | CNN, ResNet, VGG | Transformer, GPT, BERT |

---

## 4. 결론

> **둘 다 목적은 같다** — 각 층의 입력 분포를 안정시켜 학습을 빠르고 안정적으로 만드는 것.
> 차이는 어느 방향으로 묶어서 정규화하느냐.
> 그 방향 차이 하나가 적합한 데이터 유형을 완전히 갈라놓는다.

| 상황 | 선택 |
|------|------|
| 데이터 크기 고정 + 배치 크게 가능 | ✅ 배치 정규화 |
| 데이터 크기 가변 + 배치 작을 수밖에 없음 | ✅ 레이어 정규화 |
