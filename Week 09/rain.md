# Post-Training Quantization(PTQ)이 기존에 학습된 LLM을 다시 전체 학습하지 않고 경량화하는 방식을 설명하고, PTQ 적용 시 모델 성능 저하가 발생할 수 있는 원인을 분석하시오.

---

## 0. 배경 지식 — 가중치와 양자화

### 가중치란

LLM이 학습을 통해 만들어낸 수십억 개의 숫자다. 이 숫자들이 언어를 이해하는 능력 그 자체다.
가중치는 0.38291847362918 같은 정밀한 소수로 저장되며, 이런 숫자가 수십억 개면 용량이 수백 GB에 달한다.
일반 컴퓨터에서는 실행이 불가능하다.

### 양자화란

가중치 숫자의 정밀도를 줄여서 용량을 작게 만드는 것이다.

> 예: 173.2847cm → 173cm. 비슷하게 쓸 수 있는데 훨씬 간단해진다.

FP32(32비트 부동소수점) → INT8(8비트 정수)로 바꾸면 숫자 하나당 용량이 32비트에서 8비트로 줄어든다.
모델 전체 용량이 4분의 1이 된다.

---

## 1. PTQ란 무엇인가

LLM 학습은 GPU 수천 개로 몇 달씩 걸리고 비용이 수백억 원이다.
용량을 줄이려고 처음부터 다시 학습하는 건 현실적으로 불가능하다.

**PTQ(Post-Training Quantization)** = 학습이 완전히 끝난 모델에, 재학습 없이 양자화를 적용하는 것.
Post = 이후, Training = 학습. 즉 학습 이후에 양자화를 적용한다는 뜻이다.

### 동작 순서

    1단계: LLM 학습 완료
           → 수십억 개 가중치 확정, 용량 수백 GB

    2단계: PTQ 적용
           → 재학습 없이 가중치 숫자 정밀도만 줄임
           → 0.38291847 → 38

    3단계: 완성
           → 용량이 4분의 1로 줄어든 가벼운 모델
           → 일반 기기에서도 실행 가능

> **핵심**: 이미 만들어진 모델을 다시 학습하지 않고, 가중치 숫자의 정밀도만 줄여서 가볍게 만드는 것.
> 재학습 비용 없이 빠르게 적용할 수 있어서 실제 현장에서 가장 많이 쓰인다.

---

## 2. PTQ 적용 시 성능 저하 원인

### 원인 1 — 반올림 오차 누적

소수점을 버리면 원래 숫자와 약간 달라진다.

    0.38291847 → 38  (오차: 0.00291847)

이런 오차가 수십억 개 가중치에서 동시에 발생한다.
LLM은 레이어가 수십 개 있고, 앞 레이어 결과가 다음 레이어 입력으로 들어간다.

    입력 → 레이어1(오차) → 레이어2(오차) → 레이어3(오차) → ... → 최종 답

레이어를 지날 때마다 오차가 계속 더해진다.
오차가 작아도 수십 개 레이어를 지나면서 쌓이면, 최종 답에서 크게 틀려질 수 있다.
모델이 클수록 레이어가 많아서 이 문제가 더 심해진다.

---

### 원인 2 — 이상치(Outlier) 문제

가중치 숫자들이 대부분 -1 ~ 1 사이인데, 가끔 100, -200 같이 튀는 숫자가 있다. 이걸 이상치라고 한다.

INT8 양자화는 숫자를 256개 단계로 나눠서 표현한다.

| 상황 | 범위 | 한 칸 크기 | 결과 |
|------|------|-----------|------|
| 이상치 없음 | -1 ~ 1 | 2 ÷ 256 = **0.0078** | 정밀하게 표현 가능 |
| 이상치 있음 | -1 ~ 100 | 101 ÷ 256 = **0.39** | 값들이 뭉개짐 |

이상치가 있으면 한 칸이 50배 커진다.
원래 0.1이랑 0.2가 다른 숫자인데, 한 칸이 0.39니까 둘 다 같은 칸에 들어가버린다.
대부분 가중치들이 뭉개져서 정밀도가 확 떨어진다.

---

### 원인 3 — 레이어마다 민감도가 다르다

LLM 안에는 레이어가 수십 개 있다.
어떤 레이어는 양자화해도 멀쩡한데, 어떤 레이어는 조금만 건드려도 성능이 확 떨어진다.
PTQ는 재학습 없이 숫자만 줄이기 때문에, 어느 레이어가 민감한지 파악하고 대응하기 어렵다.
민감한 레이어에서 성능이 급격히 떨어질 수 있다.

---

### 원인 4 — 재학습이 없어서 오차 보정이 안 된다

양자화 후 숫자가 바뀌면 오차가 생긴다.
원래라면 학습 알고리즘이 오차를 감지하고 가중치를 자동으로 수조 번 보정한다.
PTQ는 재학습이 없다. 숫자를 줄여버리고 끝이다.
오차가 생겨도 보정할 기회가 없어서 성능 저하가 그대로 남는다.

**PTQ vs QAT 비교**

| | PTQ | QAT |
|---|---|---|
| 재학습 여부 | 없음 | 있음 |
| 비용 | 낮음 | 높음 |
| 성능 | 상대적으로 낮음 | 상대적으로 높음 |
| 적용 속도 | 빠름 | 느림 |
| 주로 쓰는 곳 | 완성된 모델 가져다 쓸 때 | 자체 모델 직접 만드는 곳 |

> QAT(Quantization-Aware Training): 양자화하면서 동시에 재학습으로 오차를 보정하는 방식. PTQ보다 성능이 좋지만 비용이 크다.

---

## 3. 결론

PTQ는 이미 완성된 LLM을 재학습 없이 가중치 정밀도만 줄여서 경량화하는 방법이다.
비용 없이 빠르게 적용할 수 있어서 실제 현장에서 가장 많이 쓰인다.
그러나 아래 네 가지 이유로 성능 저하가 발생할 수 있다.

| 원인 | 내용 |
|------|------|
| 반올림 오차 누적 | 소수점 버린 오차가 레이어마다 쌓여 최종 답이 틀려짐 |
| 이상치 문제 | 튀는 값 하나가 양자화 범위를 넓혀 대부분 값들이 뭉개짐 |
| 레이어 민감도 차이 | 민감한 레이어를 파악·대응하기 어려워 성능 급락 가능 |
| 오차 보정 불가 | 재학습이 없어서 오차가 생겨도 보정할 기회가 없음 |
