---

##  1. 개요 및 정의: 결측치(Missing Data)란?

데이터프레임(DataFrame) 이나 시리즈(Series)에서 누락된 값을 탐지하고 제거하거나 대체하는 전처리 작업을 의미함. 
Pandas에서는 결측치를 `NaN` (Not a Number) 또는 `None`으로 표기하며, 이를 적절히 가공하는 것은 데이터 정제의 첫 단추입니다.

### 5단 분석법으로 보는 결측치 처리의 본질

* 일반 명사 : 계획된 시험 배치에서 어떤 사고로 이루어지지 못한 관측 값을 절차에 따라 정리하여 마무리 짓는 행위.
* 고유 명사 : 입력된 Raw 데이터를 목적에 맞게 변환, 가공, 분석하여 유용한 정보로 만드는 일련의 파이프라인

---

## 2. 왜 결측치 처리가 필요한가?

### 1. 데이터 신뢰성 및 통계 정확도 향상
결측치(`NaN`)이 포함된 상태로 연산을 수행하면 평균, 분산, 표준편차 등 주요 지표가 심각하게 왜곡됨. Pandas를 통해 이를 정제해야만 데이터 분석 결과의 수치적 신뢰성을 확보할 수 있습니다.

### 2. 데이터 손실 최소화 및 자원 효율성 확보
무작정 빈칸에 있다고 해당 행을 지워버리면 귀찮게 수집한 나머지 데이터까지 함께 유실됨. Pandas의 정교한 대체(`fillna`) 및 보간(`interpolate`) 기법을 활용하면 가용 샘플 수(Sample Size)를 최대한 유지할 수 있습니다.

### 3. 머신러닝/AI 모델의 시스템 붕괴(에러) 방지
`Scikit-learn`이나 `PyTorch` 등 대부분의 알고리즘은 입력 데이터에 `NaN`이 포함되어 있으면 학습을 시작하지 못하고 치명적인 `ValueError`를 발생시킵니다. API 서빙 단계에서 `422` 및 `500` 서버 에러를 막기 위한 필수의 1차 방어선입니다.

## 3. 결측치 처리 핵심 파이프라인 및 기능

Pandas는 결측치를 효율적으로 다루기 위해 직관적인 5단계 프로세스를 제공합니다.

| 단계 | 동작 (Operation) | 설명 | 주요 메서드 |
| :--- | :--- | :--- | :--- |
| 1단계 | 결측치 확인| 어느 열과 행에 구멍(NaN)이 났는지 탐색 및 진단 | `isnull()`, `notnull()`, `info()` |
| 2단계 | 결측치 제거 | 분석을 방해하거나 오염도가 높은 행/열을 삭제 | `dropna()` |
| 3단계 | 결측치 대체| 대표값(평균, 중앙값 등)으로 빈칸을 정교하게 채움 | `fillna()` |
| 4단계 | 결측치 필터링 | 특정 조건을 만족하는 데이터를 남기고 결측 행을 분리 | `notnull()`, `isnull()` |
| 5단계 | 결측치 처리 후 저장| 정제가 완료된 데이터를 파일로 내보내고 재로드 | `to_csv()`, `read_csv()` |

## 4. 실무 구현 및 코드 가이드

### 4-1. 환경 세팅 및 데이터셋 로드
```python
import pandas as pd
import numpy as np

# 실무 환경을 가정한 예제 데이터프레임 생성
data = {
    '이름': ['김동욱', '오르빗', np.nan, '이영희'],
    '나이': [26, np.nan, 30, 28],
    '성별': ['남', '남', '여', np.nan]
}
df = pd.DataFrame(data)
```

### 4-2. 1단계 : 결측치 진단 및 탐지(`isnull`, `info`)

```python
# 각 요소별 결측 여부 확인 (True: 결측치)
print(df.isnull())

# [실무 필수] 각 열별 결측치 개수 총합 확인
print(df.isnull().sum())

# 데이터 요약 정보로 결측 갯수 간접 파악
df.info()
```
#### ❓ 왜 원래 정수(int)였던 '나이' 컬럼이 float64로 출력되나요?

Pandas에서 NaN은 내부적으로 부동소수(float) 타입으로 표현됩니다. 정수형 데이터와 NaN이 섞이게 되면, Pandas는 데이터 유실 없이 모든 값을 담기 위해 컬럼 전체를 자동으로 float64로 자동변환합니다


### 4-3. 2단계 : 결측치 제거 전략(`dropna`)

```python

# 1. 결측치가 하나라도 포함된 "행(Row)" 전체 삭제
df_dropped_rows = df.dropna()

# 2. 특정 열('이름')의 결측치만을 기준으로 행 삭제
df_dropped_subset = df.dropna(subset=['이름'])

# 3. 결측치가 포함된 "열(Column)" 자체를 통째로 삭제
df_dropped_cols = df.dropna(axis=1)

```

#### ❓ `dropna(axis=1)` 결과가 `Empty DataFrame`으로 나오는 이유가 무엇인가요?

`axis=1`은 열(Column) 기준 검사입니다. 본 예제 데이터셋의 모든 컬럼(['이름', '나이', '성별'])에는 최소 1개 이상의 NaN이 포함되어 있습니다. 따라서 모든 열이 삭제 조건을 충족해 데이터프레임의 뼈대(인덱스)만 남고 알맹이가 전부 증발한 상태를 의미합니다.

```python
data = {
    '이름': ['김동욱', '오르빗', np.nan, '이영희'], <-NaN이 있음
    '나이': [26, np.nan, 30, 28],               <-NaN이 있음
    '성별': ['남', '남', '여', np.nan]          <-NaN이 있음
}
```
이렇게 모든 열에 최소 한개씩 있음

#### `axis=0` vs `axis=1` 차이

axis=0 → 행 기준 (↓ 방향 검사)

         NaN 있는 행 삭제

axis=1 → 열 기준 (→ 방향 검사)

         NaN 있는 열 삭제

#### `axis=1` 적용 과정

| 열 | NaN 있음? | 결과 |
| :--- | :--- | :--- |
| 이름 | ✅ | ❌ 삭제 |
| 나이 | ✅ | ❌ 삭제 |
| 성별 | ✅ | ❌ 삭제 |

삭제할 열만 있고 남은 열이 없으니

```python
Empty DataFrame
Columns : []
Index : [0, 1, 2, 3]
```

인덱스(뼈대)만 남고 내용물이 전부 사라지는것!

### 4-4. 3단계 : 결측치 대치 및 값 채우기 (`fillna`, `ffill`, `bfill`)

- 데이터의 유효성을 유지하고 정보 손실을 막기 위해 가장 많이 쓰는 핵심 기법

```python
# 1. 딕셔너리를 활용해 열별로 정해진 특정 값 매핑 대체
df_filled_value = df.fillna(value={'이름': '없음', '나이': '없음', '성별': '없음'})

# 2. 대표값(평균) 활용 대체 (수치형 데이터 오염 방지)
df_numeric_mean = df.copy()
df_numeric_mean['나이'] = df_numeric_mean['나이'].fillna(df_numeric_mean['나이'].mean())

# 3. ffill() (Forward Fill): 주식/날씨 등 데이터에서 바로 '이전(앞)' 값으로 채우기
df_filled_forward = df_numeric_mean.ffill()

# 4. bfill() (Backward Fill): 바로 '이후(뒤)' 값으로 채우기
df_filled_backward = df_numeric_mean.bfill()
```

### 4-5. 4단계 : 결측치가 있는 행 필터링 (불리언 마스킹)

- 특정 조건에 맞는 데이터만 남기거나, 결측치만 따로 골라내어 분석할 때 사용함

```python

# 1. 이름이 결측치가 아닌(정상 입력된) 데이터만 필터링
df_no_missing = df[df['이름'].notnull()]

# 2. 성별이 비어있는(NaN) 행만 타겟팅하여 골라내기
df_filtered = df[df['성별'].isnull()]

```

### 4-6. 5단계 : 결측치 처리 후 데이터 저장(`to_csv`, `read_csv`)

- 정제가 완료된 클린 데이터를 로컬 환경에 저장하고 파이프라인으로 다시 돌아오는 단계입니다.

```python
# 1. 저장용 처리: 결측치를 지정 값으로 채우기
processed_df = df.fillna({'이름': '없음', '나이': 0.0, '성별': '없음'})

# 2. 인덱스를 제외하고 CSV 파일로 내보내기
processed_df.to_csv('cleaned_data.csv', index=False)

# 3. 저장된 CSV 파일 읽어와서 데이터프레임으로 로드하기
df_cleaned = pd.read_csv('cleaned_data.csv')
print(df_cleaned)

```

## 5. 결론 및 요약

- 결측치 처리는 데이터 분석의 첫번째 관문이자 가장 중요한 전처리 단계입니다.

### 핵심 3가지

#### 1. 왜 해야 하나?
- 결측치 방치 시 통계 왜곡, 모델 에러 발생
- 데이터 신뢰성 확보를 위한 필수 과정



#### 2. 어떻게 해야하나?

| 상황 | 방법 |
|---|---|
| 결측치 비율이 높은 행/열 | `dropna()` 로 제거 |
| 수치형 데이터 | `fillna(mean())` 평균으로 대체 |
| 시계열 데이터 | `ffill()` / `bfill()` 로 보간 |
| 범주형 데이터 | `fillna('없음')` 으로 대체 |



#### 3. 처리 순서


탐지(`isnull`) ➡️ 제거(`dropna`) ➡️ 대체 (`fillna`) ➡️ 필터링(`notnull`) ➡️ 저장(`to_csv`)
