# 데이터 증강 기법
###### 주제 : 데이터 증강 기법이 모델의 일반화 성능에 긍정적 영향을 주는 원리를 설명하고, 잘못된 증강이 오히려 모델 편향을 강화할 수 있는 사례를 제시하시오.



---


## 1. 데이터 증강이란?

**데이터 증강**은 기존의 학습 데이터셋에 인위적인 변형을 주거나, 수학적·통계적 방법을 활용하여 데이터의 양과 다양성을 늘리는 기법입니다.   

머신러닝과 딥러닝 모델은 다양한 데이터를 학습할수록 새로운 데이터에 대해 더 안정적인 예측을 합니다.
 이를 통해 모델이 특정 데이터에만 과하게 맞춰지는 과적합을 줄이고, 다양한 입력 상황에 더 잘 대응하도록 만들 수 있습니다. 

---

## 2. 데이터 증강 기법의 종류

1. 이미지 데이터   

   * 기하학적 변환 : 이미지 회전, 뒤집기, 이동, 크롭
   * 색상 및 픽셀 변환 : 밝기, 대비, 채도 조절 및 노이즈 추가
   * 영역 제거 및 혼합
     - Cutout : 이미지에 특정 영역을 검은색으로 가림
     - Mixup : 두 개의 이미를 일정 비율로 섞음
     - CutMix : 한 이미지의 작은 영역을 잘라내어 다른 이미지에 덮어씌움

2. 텍스트 데이터

    * 단어/구 교체 : 유의어 사전등을 활용해 단어를 비슷한 뜻으로 교체
    * 토큰 삽입 및 삭제 : 무작위로 불필요한 단어를 삽입하거나 중요도가 낮은 단어 삭제
    * 역번역 : 문장을 외국어로 번역했다가 다시 원래 언어로 변경

3. 정형 데이터

    * SMOTE : 소수 클래스 데이터와 그 주변의 k개의 최근접 이웃 데이터를 활용하여 직선상에 새로운 가상의 데이터를 생성
    * ADASYN :  SMOTE와 유사하나, 분류하기 어려운(경계선 근처의) 소수 클래스 데이터에 더 집중하여 데이터를 생성

4. 시계열 데이터

    * 시간 영역 변경 : 시간 축 기준 늘리기/줄이기, 데이터 흔들기, 크기 조정
    * 주파수 영역 변형: 푸리에 변환을 이용해 주파수 스펙트럼 값을 변조하여 새로운 시계열 패턴 생성


---

## 3. 데이터 증강이 일반화 성능에 긍정적 영향을 주는 원리

데이터 증강은 모델이 학습 데이터에만 과하게 맞춰지는 것을 막고, 새로운 데이터에도 안정적으로 예측할 수 있도록 도와줍니다.

1. 과적합 감소 : 과적합은 모델이 학습 데이터에는 높은 성능을 보이지만, 새로운 데이터에는 낮은 성능을 보이는 문제입니다.

2. 데이터 다양성 증가 : 모델은 다양한 데이터를 많이 학습할수록 실제 환경에서 나타나는 여러 상황에 더 잘 대응할 수 있습니다.

3. 핵심 특징 학습 : 데이터 증강은 모델이 중요하지 않은 요소보다 핵심적인 특징에 집중하도록 도와줍니다.

4. 실제 환경에 대한 대응력 향상 : 실제 환경의 데이터는 학습 데이터와 완전히 같지 않은 경우가 많은데 증강을 하게 되면 이를 보완할 수 있습니다.

5. 데이터 부족 문제 완화 : 데이터 증강은 기존 데이터를 활용하여 새로운 학습 데이터를 만들어내기 때문에 데이터 부족 문제를 어느 정도 해결할 수 있습니다.

따라서, 데이터 증강은 학습 데이터의 양과 다양성을 늘려 모델이 특정 데이터에만 의존하지 않도록 합니다.
이를 통해 모델은 데이터의 핵심 특징을 학습하고, 새로운 데이터에 대해서도 안정적인 예측을 할 수 있게 됩니다.

---

## 4. 잘못된 데이터 증강이 모델 편향을 강화하는 사례

데이터 증강은 모델의 성능을 높이는 데 도움을 줄 수 있지만, 잘못 적용하면 오히려 모델이 잘못된 기준을 학습하거나 기존 데이터의 편향을 더 강하게 만들 수 있습니다.  

특히 원본 데이터의 의미가 변하거나, 특정 클래스 또는 특정 집단에만 증강이 집중되면 모델은 실제로 중요한 특징이 아닌 인위적인 특징을 학습하게 됩니다.

1. 원본 데이터의 의미가 바뀌는 경우 : 데이터 증강은 원본 데이터의 의미가 유지되는 범위 안에서 적용되어야 합니다.
    
    숫자 이미지 분류에서 숫자 6을 180도 회전하면 9처럼 보일 수 있습니다.
    그런데 라벨을 그대로 6으로 유지한다면, 모델은 잘못된 데이터를 학습하게 됩니다.

2. 특정 클래스에만 과도하게 증강을 적용하는 경우 : 특정 클래스에만 증강을 많이 적용하면 모델이 증강 과정에서 생긴 특징을 해당 클래스의 특징으로 오해할 수 있습니다.

3. 기존 데이터 불균형을 더 키우는 경우 : 데이터 증강은 데이터 불균형을 완화하기 위해 사용되기도 하지만, 잘못 사용하면 오히려 불균형을 더 크게 만들 수 있습니다.

    모델을 학습할 때, 데이터셋이 한 쪽에 편향되어 있는 상태인데 그 데이터셋을 증강하게 되면 데이터 수는 늘어나지만 데이터의 다양성은 충분히 확보되지 않습니다.

4. 텍스트 데이터에서 문맥이 왜곡되는 경우 : 텍스트 데이터 증강에서도 문장의 의미가 바뀌면 문제가 발생할 수 있습니다.

    단어를 무작위로 삭제하거나 유의어로 교체하는 과정에서 문장의 의미가 달라질 수 있습니다.
    이때 기존 라벨을 그대로 유지하면 모델은 문장과 라벨이 맞지 않는 데이터를 학습하게 되고, 잘못된 판단 기준을 형성할 수 있습니다.

따라서, 잘못된 데이터 증강은 데이터의 의미를 왜곡하거나 특정 집단과 클래스에만 치우친 학습을 유도할 수 있습니다.

---
## 결론

데이터 증강은 기존 데이터를 변형하여 학습 데이터의 양과 다양성을 늘리는 중요한 기법입니다.
이를 통해 모델은 학습 데이터에만 과하게 맞춰지는 것을 줄이고, 새로운 데이터에 대해서도 더 안정적인 예측을 할 수 있습니다.

잘못된 증강은 데이터의 의미를 왜곡하거나 특정 클래스와 집단에 대한 편향을 강화할 수 있습니다.

따라서 데이터 증강은 단순히 데이터를 많이 늘리는 것이 아니라, 데이터의 특성과 문제 상황을 고려하여 적절하게 적용해야 합니다.
