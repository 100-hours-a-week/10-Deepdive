## 주제: 모델 추론 API에서 비동기 처리가 필요한 이유

작업을 순차적으로 처리하는 동기 처리와 달리, 비동기 처리는 작업 시간이 오래 걸리는 작업을 실행시켜 놓고 그 결과를 기다리는 동안 다른 작업을 처리한 뒤, 원래 작업이 완료되면 다시 이어서 처리하는 방식을 의미합니다.

FastAPI에서 `async/await`은 여러 작업을 실제로 동시에 실행하는 병렬성이 아니라, 여러 작업을 번갈아가며 처리하는 동시성을 띄는 방식입니다.

모델 추론 API에서 비동기 처리가 필요한 이유는 추론 자체를 빠르게 만들기 위해서가 아니고, 추론 전후에 발생하는 대기 시간 동안 서버가 다른 요청을 처리할 수 있게 하기 위함입니다.

---

### 추론 API 흐름

```text
추론 요청
- 이미지/텍스트 파일 읽기
- 외부 API 호출
- 전처리
- 모델 추론
- DB 저장
- 결과 응답
```

여기서 비동기 처리가 적합한 부분은 이미지/텍스트 파일 읽기, 외부 API 호출, DB 저장과 같이 응답을 기다리는 작업입니다.

이때 `async/await`를 사용하면 기다리는 동안 FastAPI의 이벤트 루프가 다른 요청을 처리할 수 있습니다.

FastAPI 공식 문서에서도 웹 API처럼 I/O 대기가 많은 작업에는 동시성의 이점이 있고, 머신러닝처럼 계산량이 큰 작업에는 병렬성이나 멀티프로세싱을 함께 고려할 수 있다고 나와있습니다.

여러 사용자가 동시에 요청을 보내는 상황에서 또한 비동기 처리 방식이 동기 처리 방식보다 효율적으로 처리할 수 있습니다.

---

### 동기 처리 방식

```python
def predict(file: UploadFile):
    
    # 동기 방식 파일 읽기
    image = file.file.read() 
    
    # 외부 API
    external_api_result = call_api(image)
    
    # 실제 추론, CPU/GPU 계산
    result = model.predict(image)  
    
    # DB 저장
    db.save({
        "prediction": result,
        "external_api_result": external_api_result
    })
    
    return result
```

동기 처리 방식은 코드가 단순하고 이해하기 쉽지만, 파일 읽기, DB 저장, 외부 API 호출처럼 시간이 걸리는 작업이 있을 때 해당 작업이 끝날 때까지 흐름이 막힙니다. 따라서 요청이 많으면 전체 응답 시간이 길어질 수 있습니다.

---

### 비동기 처리 방식

```python
async def predict(file: UploadFile):
    
    # 비동기 방식 파일 읽기
    image = await file.read()

    # 외부 API
    external_api_result = await async_call_api(image)

    # 실제 추론, CPU/GPU 계산
    result = await asyncio.to_thread(model.predict, image)

    # DB 저장
    await db.save({
        "prediction": result,
        "external_api_result": external_api_result
    })
    
    return result
```

비동기 처리 방식에서는 파일을 읽는 동안 서버가 멈춰 있는 것이 아니라, 이벤트 루프가 다른 요청을 처리할 수 있습니다. 따라서 파일 읽기, DB 저장, 외부 API 호출처럼 I/O 대기 시간이 많은 작업에서 서버 자원을 더 효율적으로 사용할 수 있습니다.

---

## 비동기 처리 방식의 장점

1. I/O 대기 시간 동안 다른 요청을 처리할 수 있습니다.
2. 여러 사용자의 동시 요청 처리에 유리합니다.
3. 파일 읽기, DB 저장, 외부 API 호출이 많은 서비스에서 서버 자원을 효율적으로 사용할 수 있습니다.

---

## 비동기 처리 방식의 단점

1. `async`, `await`, 이벤트 루프에 대한 이해가 필요해 코드 구조가 복잡해질 수 있습니다.
2. 동기 작업을 잘못 넣으면 이벤트 루프를 막아 오히려 다른 요청 처리가 지연될 수 있습니다.

---

## 정리

비동기 처리는 모든 작업을 빠르게 만들어주는 방식이 아니라, I/O 대기 시간이 발생하는 동안 서버가 다른 작업을 처리할 수 있게 하는 동시성 처리 방식입니다.

따라서 모델 추론 API에서는 파일 읽기, 외부 API 호출, DB 저장과 같은 작업에는 비동기 처리가 적합하지만, 전처리나 모델 추론처럼 계산량이 많은 작업은 별도의 구조를 함께 고려해야 합니다.
